Natal Astrology Engine API

Welcome to the Natal Astrology Engine API. This service allows you to generate and interpret astrological birth charts based on birth information.

Interactive API Documentation

API Endpoints

  • POST /chart

    Generate a natal chart based on birth information

  • POST /interpret

    Generate and interpret a natal chart

  • GET /house-systems

    Get available house systems and descriptions

Authentication

All API requests require an API key sent in the X-API-Key header.

Example Request
curl -X POST https://your-api-url/chart \
-H "X-API-Key: your-api-key" \
-H "Content-Type: application/json" \
-d '{
  "birth_date": "1990-06-15",
  "birth_time": "14:30",
  "latitude": 40.7128,
  "longitude": -74.0060,
  "house_system": "placidus",
  "zodiac_type": "tropical"
}'

Example Usage

Request
POST /interpret
{
  "birth_date": "1990-06-15",
  "birth_time": "14:30",
  "latitude": 40.7128,
  "longitude": -74.0060,
  "timezone": "America/New_York",
  "house_system": "placidus",
  "zodiac_type": "tropical",
  "template_name": "markdown"
}

## Moon in Libra
With Moon in Libra, your emotional nature seeks harmony and balance. You have a strong need for relationships and may avoid conflict to maintain peace. Your feelings are often influenced by those around you as you naturally attune to others.

## Ascendant in Leo
The Ascendant represents your outward personality and how others perceive you. With Leo rising, you come across as charismatic, proud, and warmly expressive.

House Systems

The API supports multiple house systems for chart calculations:

  • Placidus - Most commonly used modern system
  • Whole Sign - Ancient system where each sign equals one house
  • Equal Houses - Houses of equal size (30°)
  • Koch - Time-based system popular in Germany
  • Campanus - Medieval system using the prime vertical
  • And more... - See /house-systems endpoint

Features

  • Accurate planetary positions using flatlib
  • Automatic timezone detection from coordinates
  • Multiple house system calculations
  • Aspect calculations with applying/separating info
  • Comprehensive planet, house, and aspect interpretations
  • Customizable interpretation templates
